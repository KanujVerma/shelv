## What each classification means

- **CONNECTED_SOURCE**: actual current entry/composition mounts the named component and supplies a real request/operation port where the row claims a connected read/write. This is static control/data-flow evidence only.
- **CANDIDATE_ONLY**: isolated or unimported candidate, not a connection in this audited Root. Mere commit presence or a source-scoped review does not admit it.
- **STATIC_DESIGN_ONLY**: retained approved design context/PNG/specification without corresponding connected application behavior.
- **UNAVAILABLE_PLACEHOLDER**: parser and/or shell destination reaches an explicit unavailable component.
- **MISSING**: required behavior or producer is absent from the traced composition. Mixed cells preserve connected subsets and missing variants.

A builder proves a valid address can be created; a parser proves recognition; a component proves authored UI; a real supplied port plus finite dispatch/handler proves source connectivity. Runtime/genuine/visual/human/release evidence are further gates. An unknown endpoint, absent resolver or no-op port does not implement a service. Test counts and existence/grep hits confer no acceptance.
