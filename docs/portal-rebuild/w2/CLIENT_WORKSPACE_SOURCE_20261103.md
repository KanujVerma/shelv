## Honest records and entry

The title uses only a supplied trusted client name, otherwise **client workspace**. Denied/offline/retired states hide the supplied private name. V1 directory exposes only actual identities, state, revisions and timestamps, so no title, payment, review, readiness, service or current-publication fact is invented. Publication entries offer a specific version button only when W0 supplies an actual version-specific navigation/reader callback. Entry callbacks recheck the current ready projection and the exact row before invoking W0.

Reads start at null; successful next pages are accumulated only under the same scope. Duplicate identities or repeated cursor cycles remain unavailable. Filtering is explicitly limited to loaded records and never removes continuation. Transient errors may retain already-loaded rows only under the same live READY identity, with explicit **loaded records may be out of date** feedback and disabled entry buttons. Denial or retirement clears them. Failed next-page retry uses the same successful prefix/cursor; refresh starts at null and invalidates EOF absence before waiting.

Only a successful final loaded traversal with no working draft displays **no working draft in the loaded record**, followed by **refresh to check for changes**. It never claims a live snapshot or current absence. Nonfinal, loading, failed, denied, offline and unknown reads cannot display that absence. This corrects the proposed consumer side of the existing shared first-page/global-fanout bug; W0 still must replace its shared recovery mount with this scoped port.
