# Retired local Colima backup inventory

This checksum list records the archived local Colima/container and Supabase development-volume files created on 2026-10-10. It is integrity metadata only; it does not contain the database or container contents and cannot restore them.

The associated local profile was stopped during the Shelv storage audit. The archived volumes were local development/test state, not the app's source of truth. Shelv schema and runtime source remain in the repository. The local archive set was removed after this inventory was pushed; the separate source-preservation and portal rollback backups were retained.
