# Portal preview release — 2026-10-20

The [Shelv portal](https://portal.goshelv.com) now lets advisors open a saved draft or published plan in a read-only client view. Drafts show an Unpublished label and their saved revision. Plan, routine, payments and check-in previews suppress editing controls. Maya and Alex remain separate samples. Current approved content, product prices, optional-product behavior and ordinary client sign-in are retained.

Local checks, independent source review, public asset verification and hosted tests with existing synthetic accounts covered the release. The positive saved-draft test confirmed the exact revision, rejection of an older revision and read-only rendering; the published plan remained unchanged. Existing client return, plan, payments and check-ins were also checked. Hosted cross-tab email return and revoked/cancelled fixtures were not repeated in this release.

Shared advisor sessions remain disabled. Additional integration, secure operator setup and native-browser/hosted acceptance are still required. The current login remains available.

This documentation change records the portal release. It adds no application runtime, migration, scanner activation or session activation to GitHub main. The complete technical source/evidence handoff is retained separately for the release owner’s review.
