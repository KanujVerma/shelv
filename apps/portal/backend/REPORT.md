`evidence/source-manifest.json` identifies changed vs unchanged copied dependencies with baseline/candidate SHA-256 hashes. `evidence/backend.patch` contains only source modifications/new mapper using repository-relative paths. Other files in `source/` are unchanged dependency/test/reference copies. Integrate the four modified source files, the new mapper and migration; existing payments/checkins helper files are dependencies, not new changes.

RPC rechecks the live permanent actor/profile, active advisor `can_view`, selected target permanent identity/deletion state and enrollment. Since existing advisor access admits revoked targets, it explicitly rejects revoked enrollment for both modes. It holds the existing common client advisory lock and the case share lock, then checks exact case revision plus current intake version for draft; missing rich draft returns 404, stale revision/intake returns 409. It never substitutes published content for a draft. Published clientView is exactly `presentation_projection(target, portal_projection(target), false)`; the same actual entitled client view accompanies drafts. Draft carries only savedRevision, intakeVersion, public Presentation and public recommendations, without a fabricated publication version. Cancelled enrollment retains existing owner read visibility.

Payments are the existing SQL/`mapPaymentView` client-safe PaymentView; checkins use `checkin_projection(target,false)`/`mapCheckinClientView`, excluding private notes and photo storage descriptors. Preview does not append the ordinary payment endpoint's configured recipient; read-only UI should not require it for invoice/history display. No preview action invokes a mutation dispatcher, storage, or feature HTTP service.

## Native fixture and remaining gates

`tests/preview.sql.py` initializes its own UTF8 PostgreSQL 15 data directory under this backend directory, disables TCP (`listen_addresses=''`), and uses only this backend's private Unix socket with isolated port namespace 58427. It applies the real three copied concierge prerequisite migrations and preview candidate, creates only dummy users/data, then stops its own server and removes its own data directory in `finally`. No existing PostgreSQL cluster/port/process is stopped, reset or changed. `evidence/postgres.log` is the synthetic local log; socket and data directories are removed after runs.

The fixture models only minimal `auth.users`, `auth.uid()` request claim, profile creation/deletion fence and Storage schema needed by real concierge SQL. It does not emulate full GoTrue, PostgREST, API gateway JWT verification, Storage HTTP, hosted defaults or deployment migration history. Existing Auth transport tests use injected synthetic ports/fetch; real SQL tests exercise authenticated role, security definer entry points, ACLs and live persisted authorization. Full hosted `supabase db reset`/`supabase test db`, deployment verification and browser integration are not claimed and remain integrator/release gates. This release adds no `auth.sessions`, cookie, vault or session-context logic.
